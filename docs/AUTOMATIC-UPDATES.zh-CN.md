# 签名自动更新

Lumen 更新页面可以在路由器上检查最新正式版本、下载并验证后安装。请保持页面打开，直到更新后的页面和资源成功加载并完成确认。安装失败或页面未在限定时间内恢复时，会尝试恢复先前经过验证的签名版本；独立的保护进程还会处理更新进程意外退出，重启时也会检查尚未完成的更新。最近一次成功更新的旧版可通过“恢复上一个版本”手动恢复。

更新器不会修改 DNS、防火墙或代理规则。它先尝试 HTTPS 直连；失败后，如果已启用 OpenClash，则尝试现有的本地 HTTP 代理和第一个启用的认证条目。代理凭据留在路由器内，并通过标准输入交给下载工具，不会放进命令参数。其他代理软件不会被自动识别。页面中原有的发布历史检查仍使用浏览器自身的网络连接。

更新器仅访问固定的项目地址并处理固定的软件包名称。它使用当前主题内置的项目公钥验证签名清单，再核对软件包和固件构建信息的摘要；APK 还需要通过软件包自身的项目签名验证。项目公钥只用于本次安装的临时信任目录，不会加入系统信任库。旧版本无法验证、固件版本或包格式不匹配、缺少工具等情况会中止更新。固件版本和包格式必须与签名构建信息完全一致；资源与处理器架构无关，并不代表兼容所有 OpenWrt 或 LuCI 版本。

已安装的中文包和可选字体包会随主题一起更新。更新前检查安装计划，保留主题配置，并将经过验证的回退包保存在 `/etc/lumen-updater`；下次成功更新后，仅保留最新一次的回退集合。除了原有主题依赖，还需要 `curl`、`usign`、`flock` 和 `rpcd-mod-ucode`。平时没有持续轮询服务，重启恢复入口会保留，更新保护进程会在操作完成后退出。

首次使用前，需要先安装包含自动更新器的已验证主题包。从 v1.0.4 开始，更新器会在切换主题前保留独立的更新程序、接口和页面；即使回退到 v1.0.2 等较旧的受支持版本，仍可在 **Lumen → 检查更新** 一键安装已签名的新版。更新成功后恢复普通更新页面。保留的组件没有后台轮询服务；尚未安装过 v1.0.4 的旧版无法自行获得此功能。若上一个版本无法使用当前信任的项目公钥验证，更新会停止，不能假设仍能回退。更换密钥时，需要通过独立渠道核对并安装，或者使用旧密钥签名的可信过渡。

维护者发布正式版本时，需要保留签名的 `SHA256SUMS`、`SHA256SUMS.sig`、规定名称的软件包，以及各固件版本的签名构建信息 `BUILDINFO-openwrt-<release>.json`；上一版的回退文件也应继续保留。发布前核对包内版本、修订号和文件名，并验证签名及设备兼容性。
